## Overview

**Nova** is a modern admin dashboard template focused on clean interface design, animated interactions, and a structured foundation for building web-based administration interfaces.

Built with **Next.js, React, TypeScript, and Tailwind CSS**, Nova provides a contemporary frontend foundation that developers can adapt to their own dashboard applications and internal tools.

The project combines a component-oriented React architecture with modern UI utilities, animation capabilities, icons, notifications, theming support, and data visualization libraries.

## Getting Started

### Prerequisites

Make sure you have a current **Node.js** installation available.

### Installation

Clone the repository and install the project dependencies:

```bash
git clone https://github.com/hamzahaimeur/nova-dashboard.git
cd nova-dashboard
npm install
```

The repository URL and directory name are not specified in the provided project files, so they should be replaced with the actual values.

### Development

Start the Next.js development server:

```bash
npm run dev
```

Then open the local development URL provided by Next.js.

### Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```

### Linting

Run ESLint across the project:

```bash
npm run lint
```
